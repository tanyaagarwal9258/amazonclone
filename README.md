# 🛒 Amazon Clone

A simple Amazon homepage clone built using **HTML** and **CSS**. This project recreates the basic layout and design of the Amazon landing page to practice frontend development skills.

## 🚀 Features
- Responsive navigation bar
- Hero section/banner
- Product category cards
- Footer section
- Clean and modern UI

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📸 Preview
Amazon homepage inspired design with product categories and responsive layout.

## 🎯 Purpose
This project was created for practicing HTML and CSS concepts such as:
- Flexbox
- Grid Layout
- Positioning
- Responsive Design
- Styling and Layout Creation
